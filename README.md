# The Strength Practice

A mobile-friendly personal workout and flexibility tracker.

## Publish
This repository is designed for GitHub Pages. In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then Save.

## Privacy
Workout completion, checklists, notes and strength log are stored in the browser's local storage on the device. They are not uploaded or synced to a server. The repository contains the app source code only.
